
# 🔒 ESP32 Smart Lock & Universal IR Controller

نظام مدمج يعتمد على شريحة **ESP32** للتحكم بالقفل الكهربائي الذكي عن بُعد، بالإضافة إلى نظام إرسال أشعة تحت الحمراء (IR) للتحكم بالشاشات (Samsung)، أجهزة الرسيفر (StarSat)، والمنازل الذكية (المراوح).

---

## 📌 المميزات الأساسية

* **فتح القفل الذكي:** التحكم بنبضة الريليه لفتح القفل لمدة (250ms) تلقائياً.
* **ريموت IR شامل:** إرسال إشارات التحكم لشاشات Samsung، رسيفرات StarSat، والمراوح.
* **نظام حماية للمروحة:** يتطلب تسجيل دخول وتوكن أمان (`Token`) لتنفيذ الأوامر الخاصة بالتحكم بالهواء.
* **تحديث الكود لاسلكياً (OTA):** إمكانية رفع وتحديث الشفرة البرمجية عبر الشبكة دون الحاجة لكابل USB.
* **دعم CORS كامل:** إمكانية ربط الخادم بأي تطبيق موبايل (React Native / Flutter) أو واجهة ويب خارجية.

---

## 🛠️ العتاد المطلوب (Hardware)

* **ESP32 Development Board**
* **Relay Module (5V/12V)** (للتحكم بالقفل الكهربائي)
* **IR LED Transmitter** (مرسل الأشعة تحت الحمراء)
* **2N2222 NPN Transistor** + مقاومات (لتكبير مدى إشارة الـ IR)
* **مصدر تغذية مناسب** (12V للقفل + 5V للـ ESP32)

---

## 🔌 توصيل الأسلاك (Pinout)

| العنصر | المنفذ في ESP32 (GPIO) | الملاحظات |
| :--- | :--- | :--- |
| **Relay Signal Pin** | `GPIO 27` | التحكم بالقفل (High = فتح، Low = إغلاق) |
| **IR LED Transmitter** | `GPIO 4` | متصل عبر ترانزستور لزيادة مدى الإشارة |

## ⚙️ الإعداد والتشغيل

1. افتح مشروع الكود داخل **Arduino IDE**.
2. عدّل بيانات الشبكة المحلية الخاصة بك:
   ```cpp
   const char* ssid = "YOUR_WIFI_NAME";
   const char* password = "YOUR_WIFI_PASSWORD";

```

3. انقل الكود إلى شريحة **ESP32**.
4. افتح **Serial Monitor** بفرق سرعة `115200` لملاحظة نجاح الاتصال وطباعة العنوان:
`IP: 192.168.1.200`

## 📡 دليل استخدام الـ API (Endpoints)

### 1. فتح القفل الذكي

* **المسار:** `/api/unlock`
* **النوع:** `POST`
* **الاستجابة:**
```json
{"status":"success","message":"Unlocked","state":"unlocked"}

```



### 2. إرسال أوامر الـ IR العامة (الشاشات والرسيفر)

* **المسار:** `/api/cmd?code=COMMAND_NAME`
* **النوع:** `GET`
* **أمثلة للأوامر:**
* تشغيل شاشة سامسونج: `sam_power`
* رفع الصوت للرسيفر: `sat_volup`



### 3. تسجيل الدخول والتحكم بالمروحة

* **خطوة 1 - الحصول على التوكن:**
* **المسار:** `/api/login?pass=12345`
* **الاستجابة:**
```json
{"success":true,"token":"ESP32_FAN_AUTH_TOKEN_998877"}

```




* **خطوة 2 - إرسال أمر المروحة:**
* **المسار:** `/api/cmd?code=fan_on_speed&token=ESP32_FAN_AUTH_TOKEN_998877`



### 4. فحص حالة النظام

* **المسار:** `/api/status`
* **النوع:** `GET`
